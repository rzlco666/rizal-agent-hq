### Task 3 — Index page dan hybrid search

- [ ] **Step 1: Tulis corpus + tes gagal** di `tests/search.rs`

Corpus 20 dokumen fiktif-namun-realistis (bukan data produksi) dan 8 query
dengan expected page id. Contoh dokumen: systemd, WAL SQLite, Axum auth, Telegram
webhook, Rust redaction, Threlte scene, Notion sync, CI cache.

```rust
#[tokio::test]
async fn hybrid_search_ranks_expected_page_in_top5() {
    let (idx, corpus, queries) = fixture_index().await;
    let mut ok = 0;
    for q in &queries {
        let hits = idx.search(&q.text, 5).await.unwrap();
        if hits.iter().any(|h| h.page_id == q.expected) { ok += 1; }
    }
    let precision = ok as f64 / queries.len() as f64;
    assert!(precision >= 0.8, "precision@5 = {precision}");
}

#[tokio::test]
async fn search_is_redacted() {
    let idx = fixture_index().await;
    let hits = idx.search("ghp_abcdefghijklmnop", 5).await.unwrap();
    assert!(hits.iter().all(|h| !h.snippet.contains("ghp_")));
}
```

- [ ] **Step 2: Jalankan, pastikan gagal.**

- [ ] **Step 3: Implementasi** `index.rs` + `search.rs`

Indexer: redaksi konten → chunk → embedding (bila ada) → upsert page + replace
chunks + FTS. Search: FTS BM25 top 50 + cosine top 50 (brute force atas chunk
tersimpan) → reciprocal rank fusion `k=60` → top N. Snippet 240 karakter di
sekitar match, sudah teredaksi. `Hit { page_id, title, source, snippet, score,
vector_used }`.

- [ ] **Step 4: Jalankan, pastikan lulus.**

- [ ] **Step 5: Commit** — `feat(knowledge): hybrid bm25+vector search`

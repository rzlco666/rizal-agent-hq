### Task 1 — Client stdio/HTTP

- [ ] **Step 1: Tulis tes gagal**

```rust
#[tokio::test]
async fn stdio_client_lists_tools_and_calls_read_tool() {
    let srv = spawn_fixture_mcp_stdio().await;
    let c = McpClient::connect_stdio(srv.cmd()).await.unwrap();
    let tools = c.list_tools().await.unwrap();

    let out = c.call_tool("echo", json!({"text":"hi"})).await.unwrap();
```

- [ ] **Step 3: Implementasi** `client.rs`

### Task 3 — Tool kontrol dengan scope + policy

- [ ] **Step 1: Tulis tes gagal**

```rust
#[tokio::test]
async fn action_tool_requires_mcp_control_scope() {
    let s = HqMcpServer::test_with_scope(&["read"]);
    assert!(s.call_tool("hq_request_action", json!({"capability":"agent.prompt"})).await.is_err());
}

#[tokio::test]
async fn action_tool_goes_through_approval() {
    let s = HqMcpServer::test_with_scope(&["read","mcp.control"]);
    let out = s.call_tool("hq_request_action", json!({
        "capability":"agent.prompt","target":{"kind":"agent","id":"agent:omp"},
        "input":{"text":"ringkas"}})).await.unwrap();
    assert_eq!(out.json["outcome"], "pending_approval");
}

#[tokio::test]
async fn stdio_is_loopback_only() {
    assert!(HqMcpServer::http_without_token().call_tool("hq_overview", json!({})).await.is_err());
}
```

- [ ] **Step 2: Jalankan, pastikan gagal.**

- [ ] **Step 3: Implementasi** `auth.rs` + tool `hq_request_action`

Tool kontrol hanya tersedia bila device token punya `mcp.control`; ia memanggil
`ControlPlane::request` dengan aktor agent, sehingga policy dan approval tetap
berlaku. Tool tidak pernah mengeksekusi langsung. HTTP transport wajib bearer;
stdio hanya untuk proses lokal. Setiap panggilan dicatat di audit.

- [ ] **Step 4: Jalankan, pastikan lulus.**

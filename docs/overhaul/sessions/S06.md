- [ ] **Step 2: Jalankan, pastikan gagal.**

- [ ] **Step 3: Implementasi** `auth.rs`

Middleware urutan: resolve peer (`ConnectInfo`), reject `X-Forwarded-For` bila
trust loopback, lalu Bearer/cookie; cookie mutation wajib `X-CSRF-Token` =
cookie `csrf`. Token disimpan `sha256` heksadesimal di `devices.token_hash`.
`POST /auth/ws-ticket` mengembalikan tiket 32 byte base64url, disimpan di
`Mutex<HashMap<String, WsTicket>>`, sekali pakai, 60 detik, terikat device.
`POST /auth/pair` menukar kode dari `hq device add` (8 karakter, disimpan
sebagai hash, TTL 10 menit, sekali pakai) menjadi token scoped; `GET /devices`
dan `DELETE /devices/{id}` untuk daftar/cabut. CLI `hq device add --name
--scope` mencetak kode sekali dan tidak menyimpannya mentah.
`AuthContext` masuk ke request extension. Endpoint baca butuh scope `read`;
endpoint kontrol butuh capability (S24).

- [ ] **Step 4: Jalankan, pastikan lulus.**

async fn agent_detail_honors_as_of() {

    let id = "agent:omp";
    let now: serde_json::Value = body_json(
        get(app, &format!("/api/v1/agents/{id}"), loopback()).await).await;

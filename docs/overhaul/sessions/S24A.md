async fn deny_writes_requested_and_denied_and_audit() {

- [ ] **Step 3: Implementasi** `control_plane.rs`

### Task 4 — Approval queue, nonce, expiry, CAS

- [ ] **Step 1: Tulis tes gagal** `tests/approval.rs`

```rust
#[tokio::test]
async fn approval_replay_is_rejected() {
    let (cp, _s) = pending_approval().await;
    let n = cp.nonce_for_test("a1");
    assert!(cp.decide("a1", Decision::Approve, &n, owner()).await.is_ok());
    assert_eq!(cp.decide("a1", Decision::Approve, &n, owner()).await.unwrap_err().code, "approval_already_decided");
}

#[tokio::test(start_paused = true)]
async fn approval_expires_as_denied() {
    let (cp, store) = pending_approval().await;
    tokio::time::advance(Duration::from_secs(901)).await;
    cp.sweep_expired().await.unwrap();
    assert_eq!(cp.state("a1").await.unwrap(), ApprovalState::Expired);
    assert!(store.has_event(EventKind::ActionDenied).await);
}

#[tokio::test]
async fn approval_executes_at_most_once() {
    let (cp, _s) = approved_approval().await;
    let (a, b) = tokio::join!(cp.claim("a1"), cp.claim("a1"));
    assert!(a.is_ok() ^ b.is_ok());
}
```

- [ ] **Step 2: Jalankan, pastikan gagal.**

- [ ] **Step 3: Implementasi** `approval.rs`

State 7: `pending|approved|denied|expired|executing|executed|failed`. Nonce 16
byte base64url, hanya `sha256` di payload event; nonce mentah hanya di response
pembuat. TTL 15 menit; sweeper 30 detik; saat start expire pending. Claim
`approved→executing` dengan `UPDATE ... WHERE state='approved'`; dua eksekusi
paralel tidak mungkin. Deny/expiry menghentikan eksekusi.

- [ ] **Step 4: Jalankan, pastikan lulus.**

- [ ] **Step 5: Commit** — `feat(control): approval state machine and CAS claim`

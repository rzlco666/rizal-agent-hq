# S15 — Office Objects, 2D Fallback, Performance

> **Prasyarat:** S14 lulus · **Spec:** `00-design.md` §14.1 · `06-frontend.md` §7
> **Estimasi:** 2–3 jam · **Milestone:** M4

**Goal:** Objek di kantor membawa data nyata, bisa diklik, dan kantor tetap
berguna saat 3D dimatikan atau perangkat lemah.

**Files:**
- Create: `web/src/lib/office/objects.ts`
- Create: `web/src/lib/components/office/{Whiteboard,AlertBoard,ServerRack,MeetingTable,Office2D}.svelte`
- Modify: `web/src/routes/office/+page.svelte`
- Test: `web/src/lib/office/objects.test.ts`
- Test: `web/tests/e2e/office-objects.spec.ts`, `web/tests/visual/office-2d.spec.ts`
- Test: `web/tests/e2e/office-reduced-motion.spec.ts`

**Interfaces:**
- Consumes: `live` store (`tasks`, `alerts`, `agents`, `approvals`).
- Produces: `objectModel(snapshot) -> OfficeObject[]`,
  `Office2D` props `{ agents, onSelect }`, toggle `office-mode=3d|2d`.

### Task 4 — Day/night dan reduced motion

- [ ] **Step 1: Tulis tes gagal**

```ts
test("reduced motion disables walk cycle but keeps position", async ({ page }) => {
  await page.emulateMedia({ reducedMotion: "reduce" });
  await page.goto("/office");
  const p1 = await page.evaluate(() => window.__hqOffice?.positions[0]);
  await page.waitForTimeout(800);
  const p2 = await page.evaluate(() => window.__hqOffice?.positions[0]);
  expect(p1).toEqual(p2);
  await expect(page.getByTestId("office-ready")).toBeVisible();
});
```

- [ ] **Step 2: Jalankan, pastikan gagal.**

- [ ] **Step 3: Implementasi**

Day/night dari jam `Asia/Jakarta`: key light lebih hangat dan rendah pada
malam; tidak ada color wash di permukaan. Reduced motion: agent langsung di
posisi tujuan, walk cycle mati, blink diganti opacity statis; kamera tidak
auto-animate. Semua transisi 150–300 ms.

- [ ] **Step 4: Jalankan, pastikan lulus.**

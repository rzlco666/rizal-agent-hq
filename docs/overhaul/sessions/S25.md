# S25 — Migrasi Data, Paritas, Cutover

> **Prasyarat:** semua sesi inti lulus · **Spec:** `00-design.md` §16 · `09-roadmap.md` §3
> **Estimasi:** 3 jam + 24 jam observasi · **Milestone:** M7

**Goal:** Data v2 pindah tanpa kehilangan bukti, paritas lulus, layanan berganti
ke v3, dan rollback terbukti — bukan diasumsikan.

**Files:**
- Create: `crates/hq-server/src/migrate/{mod,snapshots,notion,summaries,alerts,heartbeats,config,verify}.rs`
- Create: `crates/hq-server/tests/migrate.rs`
- Create: `crates/hq-server/tests/fixtures/v2.db` (dibuat oleh helper)
- Create: `docs/overhaul/evidence/S25.md`
- Modify: `crates/hq-server/src/cli.rs` (`migrate`)
- Modify: `scripts/install.sh`, `systemd/rizal-agent-hq.service`
- Modify: `README.md`, `CHANGELOG.md`
- Delete (setelah 24 jam): `legacy/`

**Interfaces:**
- Consumes: v2 SQLite (`snapshots`, `notion_docs`, `notion_sources`,
  `llm_summaries`, `alert_state`, `heartbeats/*.json`, `stocks.json`,
  `notion.json`), `Store`, `Ingestor`, `KnowledgeIndexer`, parity CLI.
- Produces: `hq migrate --from --to --dry-run --json`, `MigrateReport`,
  `docs/overhaul/evidence/S25.md`, unit systemd v3.

# S13 — Office Core

> **Prasyarat:** S07 lulus · **Spec:** `00-design.md` §14.1 · `06-frontend.md` §7
> **Estimasi:** 3 jam · **Milestone:** M4

**Goal:** Diorama isometrik yang tenang dan presisi: lantai, zona, meja, kamera,
cahaya — render-on-demand, bukan game loop yang membakar GPU.

**Files:**
- Create: `web/src/routes/office/+page.svelte`
- Create: `web/src/lib/office/{layout,materials,lighting,camera,scene}.ts`
- Create: `web/src/lib/components/office/{OfficeCanvas,OfficeControls,ZoneStrip,AgentList}.svelte`
- Test: `web/src/lib/office/layout.test.ts`
- Test: `web/tests/e2e/office.spec.ts`, `web/tests/visual/office.spec.ts`

**Interfaces:**
- Consumes: `live` store (`AgentCard[]`), `theme` store.
- Produces: `layoutAgents(agents: AgentCard[]): DeskAssignment[]`,
  `OfficeCanvas` props `{ agents, onSelect }`, camera presets
  `isometric|top|focus`, `invalidate()`.

## Tasks

### Task 1 — Layout deterministik

- [ ] **Step 1: Tulis tes gagal** `layout.test.ts`

```ts
test("assigns a unique desk per agent and is stable", () => {
  const agents = Array.from({ length: 40 }, (_, i) => agent(`agent:x${i}`));
  const a = layoutAgents(agents);
  const b = layoutAgents([...agents].reverse());
  expect(new Set(a.map(d => d.deskId)).size).toBe(40);
  expect(a.map(d => d.agentId)).toEqual(b.map(d => d.agentId));
});

test("zones group by runtime family", () => {
  const a = layoutAgents([agent("agent:omp"), agent("agent:cursor"), agent("agent:mcp/sql")]);
  expect(a.find(d => d.agentId === "agent:omp")!.zone).toBe("omp");
  expect(a.find(d => d.agentId === "agent:cursor")!.zone).toBe("cursor");
  expect(a.find(d => d.agentId === "agent:mcp/sql")!.zone).toBe("mcp");
});
```

- [ ] **Step 2: Jalankan, pastikan gagal.**

- [ ] **Step 3: Implementasi** `layout.ts`

Satu lantai 40×30 unit. Enam zona: muse, omp, workers, cursor, mcp, meeting.
Meja 6 per zona + 4 fleksibel. Assignment: keluarga runtime dulu, lalu hash id
stabil ke slot bebas; agen >40 memakai slot agregat `+N` di zona masing-masing.
Posisi tidak pernah berubah selama id sama.

- [ ] **Step 4: Jalankan, pastikan lulus.**

- [ ] **Step 3: Implementasi** `scene.ts` + `materials.ts` + `lighting.ts`

Threlte `<Canvas>` orthographic, latar `--ground`. Lantai material matte pasir;

### Task 3 — Kamera dan render-on-demand

- [ ] **Step 1: Tulis tes gagal**

```ts
test("camera presets change projection target", async ({ page }) => {
  await page.goto("/office");
  await page.getByRole("button", { name: "Atas" }).click();
  await expect(page.getByTestId("camera-preset")).toHaveText("top");
});

test("idle scene stops rendering", async ({ page }) => {
  await page.goto("/office");
  const n1 = await page.evaluate(() => window.__hqFrames ?? 0);
  await page.waitForTimeout(1000);
  const n2 = await page.evaluate(() => window.__hqFrames ?? 0);
  expect(n2 - n1).toBeLessThanOrEqual(2);
});
```

- [ ] **Step 2: Jalankan, pastikan gagal.**

- [ ] **Step 3: Implementasi** `camera.ts` + `OfficeCanvas`

Ortho isometrik (azimuth 45°, elevation 35,264°), OrbitControls damping, zoom
0,6–2,2, pan dibatasi. Preset `isometrik`, `atas`, `fokus`. `invalidate()` hanya
saat data berubah, kamera bergerak, atau animasi aktif; setelah 2 detik idle,
loop berhenti. Instrumentasi `window.__hqFrames` hanya di dev.

- [ ] **Step 4: Jalankan, pastikan lulus.**

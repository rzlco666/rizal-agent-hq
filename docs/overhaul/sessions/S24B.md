- [ ] **Step 2: Jalankan, pastikan gagal.**

- [ ] **Step 3: Implementasi** `omp.rs` + `process.rs`

OMP prompt: `omp -p <text> --cwd <cwd> --mode=json --no-session`; timeout 120 s;
output JSON di-parse; jika gagal, `action.failed`. Mode tmux: `tmux send-keys -t
<session> -l -- <text>` lalu `Enter`; hanya session yang terdaftar. Stop/pause:

`/proc/<pid>/stat`; PID berubah → `Denied`. Proses tersupervisi hanya anak
proses yang diluncurkan HQ, bukan unit systemd arbitrer.

### Task 5 — Ticket approval untuk UI

- [ ] **Step 1: Tulis tes gagal**

```rust
#[tokio::test]
async fn owner_can_get_one_time_ticket_for_pending_approval() {
    let app = app_with_pending();
    let t = post(app.clone(), "/api/v1/approvals/a1/ticket", json!({}), loopback()).await;
    assert_eq!(t.status(), 200);
    let nonce = body_json(t).await["nonce"].as_str().unwrap().to_string();
    assert_eq!(post(app.clone(), "/api/v1/approvals/a1/approve", json!({"nonce":nonce}), loopback()).await.status(), 200);
    assert_eq!(post(app, "/api/v1/approvals/a1/approve", json!({"nonce":nonce}), loopback()).await.status(), 409);
}

#[tokio::test]
async fn ticket_requires_owner_and_audits() {
    let app = app_with_pending();
    assert_eq!(post(app, "/api/v1/approvals/a1/ticket", json!({}), remote()).await.status(), 401);
}
```

- [ ] **Step 2: Jalankan, pastikan gagal.**

- [ ] **Step 3: Implementasi**

hash diverifikasi ulang sebelum eksekusi.

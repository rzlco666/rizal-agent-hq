### Task 1 — ID dan subject kanonik

- [ ] **Step 1: Tulis tes gagal** di `tests/subject.rs`

```rust
#[test]
fn subject_keys_are_canonical() {
    assert_eq!(Subject::Agent(AgentId::parse("agent:omp").unwrap()).key(), "agent:omp");
    assert_eq!(Subject::Session(SessionId::parse("agent:omp/session/s1").unwrap()).key(),
               "agent:omp/session/s1");

    assert_eq!(Subject::Usage(UsageScope::Agent(AgentId::parse("agent:omp").unwrap())).key(),

fn subject_rejects_bad_ids() {
```

### Task 2 — EventKind, payload, validasi skema

- [ ] **Step 1: Tulis tes gagal** di `tests/event_schema.rs`

```rust
#[test]
fn every_kind_has_a_schema() {
    for kind in EventKind::ALL {
        let schema = schema_for(kind, 1).expect("schema");
        assert_eq!(schema["type"], "object");
    }
}

#[test]
fn missing_required_field_is_rejected() {
    let draft = EventDraft::test_with_payload(EventKind::UsageRecorded, serde_json::json!({}));
    assert!(matches!(draft.validate(), Err(CoreError::Schema(_))));
}

#[test]

    assert!(schema_for(EventKind::AgentObserved, 99).is_err());

```

- [ ] **Step 2: Jalankan, pastikan gagal**

`cargo test -p hq-core --test event_schema` → gagal.

- [ ] **Step 3: Implementasi**

`EventKind` = enum desain dengan `ALL`, `as_str`, serde snake_case. Payload
struct per kind di `payload.rs`, derive `Serialize/Deserialize/JsonSchema`.
`schema_for` memakai `schemars::schema_for!` dan cache `OnceLock`. Validasi
memakai `jsonschema::validator_for`; pesan error menyebut path field.
`EventDraft::validate()` menolak `event_ts_ms <= 0`, subject kosong, payload
bukan object, dan schema mismatch.

- [ ] **Step 4: Jalankan, pastikan lulus**

`cargo test -p hq-core --test event_schema` → PASS.

- [ ] **Step 5: Commit** — `feat(core): closed event catalog with schema validation`

### Task 4 — Redaksi v2

- [ ] **Step 1: Tulis corpus**

`secrets.txt` berisi minimal: AWS `AKIA...`, GitHub `ghp_`, `github_pat_`,
OpenAI `sk-`, JWT tiga segmen, blok `-----BEGIN PRIVATE KEY-----`, header
`Authorization: Bearer abc`, `password=hunter2`, DSN
`postgres://user:pass@host/db`, dan string acak 40 karakter campuran.
`expected_secrets.txt` berisi output yang diharapkan (`[REDACTED]` per pola).
`safe.txt` berisi git SHA 40 hex, UUID v4, ULID 26 karakter, nama file, dan
angka biasa — semuanya harus tidak berubah.

- [ ] **Step 2: Tulis tes gagal** di `tests/redaction.rs`

```rust
#[test]
fn corpus_secrets_are_redacted() {
    let input = include_str!("corpus/redaction/secrets.txt");
    let expected = include_str!("corpus/redaction/expected_secrets.txt");
    assert_eq!(redact_text(input), expected);
}

#[test]
fn safe_values_survive() {
    let input = include_str!("corpus/redaction/safe.txt");
    assert_eq!(redact_text(input), input);
}

#[test]
fn redaction_is_idempotent() {
    let once = redact_text(include_str!("corpus/redaction/secrets.txt"));
    assert_eq!(redact_text(&once), once);
}

#[test]
fn redacts_nested_json_strings() {
    let mut v = serde_json::json!({"msg": "token ghp_abcd1234", "n": 1});
    redact_json(&mut v);
    assert!(!v.to_string().contains("ghp_"));
    assert_eq!(v["n"], 1);
}
```

- [ ] **Step 3: Jalankan, pastikan gagal.**

- [ ] **Step 4: Implementasi** `redact.rs`

Regex berurutan, satu `RegexSet` untuk deteksi cepat. Pola yang diganti menjadi
`[REDACTED:<kind>]`. Jangan memakai satu aturan entropy buta; batasi pada token
≥32 karakter dengan minimal 3 kelas dan bukan hex murni. `redact_json` berjalan
rekursif pada string; key tidak diubah. Dokumentasikan pola di komentar atas.

- [ ] **Step 5: Jalankan, pastikan lulus**

`cargo test -p hq-core --test redaction` → PASS.

- [ ] **Step 6: Commit** — `feat(core): redaction v2 with secret and false-positive corpus`

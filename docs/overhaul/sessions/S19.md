# S19 — Telegram Connector

> **Prasyarat:** S17 lulus · **Spec:** `00-design.md` §11 · `04-control-plane.md` §5.5

## Tasks

### Task 1 — Kirim alert dengan tombol inline

- [ ] **Step 1: Tulis tes gagal**

```rust
#[tokio::test]
async fn alert_send_has_inline_ack_and_snooze() {
    let srv = mock_tg().route("/botTOKEN/sendMessage", ok(json!({"ok":true}))).await;
    let n = TelegramNotifier::test(&srv.uri(), "TOKEN", 42);
    let d = n.send(&critical_alert("a1")).await.unwrap();
    assert!(d.ok);
    let body = srv.last_body();
    assert!(body.contains("\"callback_data\":\"ack:a1\""));
    assert!(body.contains("\"callback_data\":\"snooze:a1:60\""));
}

#[tokio::test]
async fn long_message_is_chunked_and_redacted() {
    let srv = mock_tg().route("/botTOKEN/sendMessage", ok(json!({"ok":true}))).await;
    let n = TelegramNotifier::test(&srv.uri(), "TOKEN", 42);
    n.send(&long_alert_with_secret()).await.unwrap();
    assert!(srv.calls() >= 2);
    assert!(!srv.last_body().contains("ghp_"));
}
```

- [ ] **Step 2: Jalankan, pastikan gagal.**

- [ ] **Step 3: Implementasi** `send.rs` + `types.rs`

`sendMessage` ke `owner_chat_id`, parse_mode HTML minimal (escape), maks 4096
karakter per pesan (potong di batas baris), inline keyboard: `Ack`, `Snooze 1
jam`; untuk approval: `Setujui`/`Tolak` dengan `callback_data =
ap:<approval_id>:<a|d>:<nonce>` (≤64 byte). 429 → tunggu `retry_after` lalu
retry maks 3; 5xx → backoff. Token hanya di URL/secret, tidak pernah di log.

- [ ] **Step 4: Jalankan, pastikan lulus.**

- [ ] **Step 5: Commit** — `feat(telegram): alert delivery with inline actions`

```rust
#[tokio::test]
async fn callback_from_foreign_chat_is_ignored() {
    let c = tg_webhook("s3cret").with_owner_chat(42);
    let u = callback_update(chat_id(99), "ack:a1");
    let out = c.handle_webhook(req_with_update(u)).await.unwrap();
    assert!(out.is_empty());
}
```

- [ ] **Step 2: Jalankan, pastikan gagal.**

- [ ] **Step 3: Implementasi** `webhook.rs`

Verifikasi `X-Telegram-Bot-Api-Secret-Token`. Hanya update dari
`owner_chat_id` yang diproses; chat lain diabaikan + log warn. `callback_query`:
`ack:<id>` → AlertAcknowledged; `snooze:<id>:<minutes>` → AlertSnoozed;
`ap:<id>:<a|d>:<nonce>` → `ApprovalDispatch::decide_from_channel` dengan aktor
owner. Selalu `answerCallbackQuery` (teks hasil) dan edit pesan asli (hapus
keyboard). Callback ganda → state saat ini, tanpa eksekusi kedua.

- [ ] **Step 4: Jalankan, pastikan lulus.**

- [ ] **Step 5: Commit** — `feat(telegram): verified webhook and callbacks`

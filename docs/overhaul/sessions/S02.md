# S02 — Store, Projection, Replay, Backup

> **Prasyarat:** S01 lulus · **Spec:** `00-design.md` §9.4 · `01-architecture.md` §3
> **Estimasi:** 3 jam · **Milestone:** M0

**Goal:** Event log atomik dengan projection inti, rebuild yang identik, dan
backup yang bisa direstore.

**Files:**
- Create: `crates/hq-store/migrations/0001_init.sql`
- Create: `crates/hq-store/src/{lib,db,migrations,writer,events,error,replay,backup}.rs`
- Create: `crates/hq-store/src/projections/{mod,agents,usage,alerts}.rs`
- Test: `crates/hq-store/tests/{open,append,projection,rebuild,backup,recovery}.rs`
- Modify: `crates/hq-store/Cargo.toml` (rusqlite bundled, r2d2, r2d2_sqlite, tokio, tempfile, insta)

**Interfaces:**
- Consumes: `EventDraft`, `Event`, `Seq`, `Subject`, `EventKind`, `redact_text`.
- Produces: `Store::open`, `append`, `read_since`, `query_events`,
  `agents()`, `patches()`, `rebuild`, `backup`; `Projector` trait.

- [ ] **Step 3: Implementasi** `writer.rs`

`StoreInner` menyimpan `std::sync::mpsc::Sender<WriteCmd>` ke thread writer yang
memiliki `rusqlite::Connection`. `append` mengirim command + `oneshot` reply.
Writer: `BEGIN IMMEDIATE`; untuk tiap draft: validasi, cek idempotency, insert,

baru broadcast. Error → `ROLLBACK`, tidak ada event. Failpoint tes hanya
`#[cfg(test)]`.

    fn name(&self) -> &'static str;

### Task 6 — Backup dan recovery

#[tokio::test]
async fn backup_opens_and_counts_match() {
    let (store, _dir) = test_store().await;
    seed_events(&store).await;
    let out = tempfile::tempdir().unwrap().path().join("hq.db");
    store.backup(&out).await.unwrap();

    assert_eq!(store.count_events().await.unwrap(), copy.count_events().await.unwrap());

#[tokio::test]
async fn restart_after_failed_commit_recovers() {

    drop(store);
    let reopened = Store::open(StoreOptions::for_dir(dir.path())).await.unwrap();
    assert_eq!(reopened.count_events().await.unwrap(), 0);

## Acceptance

- [ ] Append + projection atomik; failpoint tidak meninggalkan event.
- [ ] Idempotency dan seq monoton.
- [ ] Patch dikirim setelah commit, bukan sebelum.
- [ ] Rebuild menghasilkan read model identik dan tidak menulis event.
- [ ] Backup bisa dibuka dan jumlahnya sama.
- [ ] Restart setelah commit gagal bersih.

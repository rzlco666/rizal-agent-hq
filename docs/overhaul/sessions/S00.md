## Tasks

### Task 1 — Bekukan oracle sebelum menyentuh kode

- [ ] **Step 1: Catat identitas oracle**

```bash
mkdir -p tools/parity/oracle tools/parity/fixtures
cp ~/rizal-agent-hq/bin/rizal-agent-hq tools/parity/oracle/rizal-agent-hq-v2
cp -r ~/rizal-agent-hq/web tools/parity/oracle/web-v2
systemctl --user cat rizal-agent-hq > tools/parity/oracle/unit-v2.txt
~/rizal-agent-hq/bin/rizal-agent-hq --version > tools/parity/oracle/version-v2.txt 2>&1 || true
```

- [ ] **Step 2: Tulis `tools/parity/freeze.sh`**

Script menerima `--duration 1200 --interval 6`, menulis
`fixtures/state-<ts>.json` dari `GET http://127.0.0.1:8900/api/state`, dan pada
20 sampel pertama menulis `fixtures/evidence-<ts>/{ps,omp-stats,tmux,docker,git,sessions}.txt`.
Gunakan `set -euo pipefail`, `curl -fsS`, dan `date -u +%Y%m%dT%H%M%SZ` untuk nama.
Akhir script: `sha256sum` semua artifact ke `fixtures/MANIFEST.sha256`.

- [ ] **Step 3: Jalankan pembekuan** (20 menit; boleh ditinggal)

```bash
chmod +x tools/parity/freeze.sh
tools/parity/freeze.sh --duration 1200 --interval 6
```

Expected: 200 file `state-*.json`, 20 direktori evidence, `MANIFEST.sha256`.

- [ ] **Step 4: Tulis `tools/parity/verify.sh`**

Membaca `MANIFEST.sha256` dan `sha256sum -c`; exit 0 hanya jika semua cocok.
Tambahkan pengecekan jumlah: `test "$(ls fixtures/state-*.json | wc -l)" -eq 200`.

- [ ] **Step 5: Verifikasi**

```bash
tools/parity/verify.sh
```
Expected: semua `OK`, exit 0.

- [ ] **Step 6: Tulis `aliases.json`**

Petakan id v2 ke subject v3: `omp`→`agent:omp`, `cursor`→`agent:cursor`,
`Muse`→`agent:muse`, `mcp`→`agent:mcp/*`, `omp-workers-agg`→
`agent:omp/worker/*`, `coding-agents`→`agent:*`. Bentuk:

```json
{ "omp": "agent:omp", "cursor": "agent:cursor", "Muse": "agent:muse" }
```

- [ ] **Step 7: Commit**

```bash
git add tools/parity docs/overhaul/decisions
git commit -m "chore(parity): freeze v2 oracle, fixtures, and alias map"
```

### Task 3 — CI dan kualitas

- [ ] **Step 1: Tulis `deny.toml`**

Allow licenses: MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC, Unicode-3.0,
MPL-2.0, OFL-1.1. Deny wildcard dependencies; advisory database aktif; tidak ada
duplikat crate untuk paket yang sama (warn).

- [ ] **Step 2: Tulis `.github/workflows/ci.yml`**

Job `rust`: checkout, toolchain dari `rust-toolchain.toml`, cache
`Swatinem/rust-cache`, `cargo fmt --all -- --check`,
`cargo clippy --workspace --all-targets -- -D warnings`,
`cargo test --workspace`, `cargo deny check`.
Job `parity`: jalankan `tools/parity/verify.sh` (fixture disimpan di repo).

- [ ] **Step 3: Tulis `tools/checks/ci-config.sh`**

Validasi YAML dengan Python (`yaml.safe_load`), pastikan file ada dan tidak ada
`continue-on-error: true`. Exit non-zero bila gagal.

- [ ] **Step 4: Jalankan**

```bash
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
cargo deny check
bash tools/checks/ci-config.sh
```
Expected: semua exit 0.

- [ ] **Step 5: Commit**


### Task 1 — Auth dan poll

- [ ] **Step 1: Tulis tes gagal**

```rust
#[tokio::test]
async fn poll_maps_open_prs_and_failed_ci() {
    let srv = mock_github()
        .route("/repos/o/r/pulls", ok(json!([pr(12, "open")])))
        .route("/repos/o/r/actions/runs", ok(json!({"workflow_runs":[run(7, "failure")]})))
        .await;
    let c = GithubConnector::test(&srv.uri(), "tok");
    let ev = c.poll(&ctx()).await.unwrap();
    assert!(ev.iter().any(|e| e.payload["event_type"] == "pr.opened" && e.payload["data"]["number"] == 12));
    assert!(ev.iter().any(|e| e.payload["event_type"] == "workflow.failed" && e.payload["data"]["conclusion"] == "failure"));
}

#[tokio::test]
async fn unauthorized_marks_connector_auth_failed() {
    let srv = mock_github().route("/repos/o/r/pulls", status(401)).await;
    let c = GithubConnector::test(&srv.uri(), "bad");
    let err = c.poll(&ctx()).await.unwrap_err();
    assert_eq!(err.code(), "auth");
}
```

- [ ] **Step 2: Jalankan, pastikan gagal.**

- [ ] **Step 3: Implementasi** `auth.rs` + `poll.rs`

Header: `Accept: application/vnd.github+json`, `X-GitHub-Api-Version:
2022-11-28`, `User-Agent: rizal-agent-hq/3`. PAT dari
`${secret:github.token}`. Poll repos dari config (`repos: [owner/name]`),
endpoint pulls/actions runs/issues, `per_page=20`, ETag conditional. Rate limit:
baca `X-RateLimit-Remaining/Reset`; <100 → perlambat; 403/429 dengan reset →
backoff sampai reset. Setiap item → `ConnectorEvent` dengan data yang
diredaksi, `subject_hint = github:<repo>`, idempotency
`github:<event>:<repo>:<id>:<updated_at>`.

- [ ] **Step 4: Jalankan, pastikan lulus.**

- [ ] **Step 5: Commit** — `feat(github): authenticated poll for pr, ci, issues`

### Task 2 — Webhook signature dan replay

- [ ] **Step 1: Tulis tes gagal**

```rust
#[test]
fn signature_uses_sha256_hmac_and_delivery_id() {
    let body = br#"{"action":"opened"}"#;
    let sig = sign_github("secret", body);
    assert!(verify_github("secret", body, &sig, "d-1", now()).is_ok());
    assert!(verify_github("other", body, &sig, "d-1", now()).is_err());
}

#[tokio::test]
async fn replay_is_rejected() {
    let c = webhook_connector("secret");
    let req = signed_request("d-1", now());
    assert!(c.handle_webhook(req.clone()).await.is_ok());
    assert_eq!(c.handle_webhook(req).await.unwrap_err().code(), "replay");
}
```

- [ ] **Step 2: Jalankan, pastikan gagal.**

- [ ] **Step 3: Implementasi** `webhook.rs`

Verifikasi `X-Hub-Signature-256` (`sha256=` + HMAC-SHA256 body), delivery id
`X-GitHub-Delivery` sebagai idempotency, timestamp event ≤5 menit, replay store
in-memory + persisted `connector_runs`. Payload `pull_request`, `workflow_run`,
`issues`, `issue_comment`, `push` dipetakan ke tipe yang sama dengan poll.
Signature salah/expired/replay → 401/409; tidak pernah menulis event.

- [ ] **Step 4: Jalankan, pastikan lulus.**

- [ ] **Step 5: Commit** — `feat(github): verified webhooks with replay protection`

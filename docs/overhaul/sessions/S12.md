# S12 — Agent Detail

> **Prasyarat:** S11 lulus · **Spec:** `00-design.md` §14 · `06-frontend.md`
> **Estimasi:** 3 jam · **Milestone:** M3

**Goal:** Satu agent bisa dijelaskan lengkap: sekarang, tugas, log, biaya,
sesi/file, dan alert — tanpa berpindah halaman.

**Files:**
- Create: `web/src/routes/agents/[id]/+page.svelte`
- Create: `web/src/routes/agents/[id]/+page.ts` (load)
- Create: `web/src/lib/components/{AgentHeader,TaskList,LogView,UsagePanel,SessionsPanel,EvidenceBadge}.svelte`
- Create: `web/src/lib/format/usage.ts`
- Test: `web/tests/e2e/agent-detail.spec.ts`
- Test: `web/src/lib/format/usage.test.ts`
- Modify: `web/src/lib/api/client.ts` (getAgentDetail, getAgentLogs, getAgentUsage)

**Interfaces:**
- Consumes: `GET /agents/{id}`, `/tasks`, `/logs`, `/usage`, `/sessions`, `/files`;
  `AgentDetail`, `TaskView`, `LogView`, `UsageReport`, `SessionView`.
- Produces: route `/agents/[id]`, komponen tab, `formatTokens`, `formatUsd`,
  `formatDuration`.

### Task 4 — RSS dan Docker

- [ ] **Step 1: Tulis YAML + tes**

```rust
#[tokio::test]
async fn rss_poll_maps_items() {
    let srv = mock_rss(feed_xml(3)).await;
    let c = preset_with(&srv, "rss");
    let ev = c.poll(&ctx()).await.unwrap();
    assert_eq!(ev.len(), 3);
    assert_eq!(ev[0].payload["event_type"], "feed.item");
}

#[tokio::test]
async fn docker_events_and_restart() {
    let srv = mock_docker().await;
    let c = preset_with(&srv, "docker");
    let ev = c.poll(&ctx()).await.unwrap();
    assert!(ev.iter().any(|e| e.payload["event_type"] == "container.health_changed"));
    assert!(c.action("restart_container", json!({"id":"abc"})).await.is_ok());
}
```

- [ ] **Step 2–5:** RSS: parse XML (feed-rs), dedupe by guid/link, event
  `feed.item`, tanpa action. Docker: HTTP API via `DOCKER_HOST` tcp/TLS (unix
  socket didokumentasikan sebagai batas v1), poll containers + events, actions
  `start/stop/restart_container` (capability + approval), rate limit 10/detik.

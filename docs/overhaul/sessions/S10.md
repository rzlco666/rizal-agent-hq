# S10 — Collector Runtime B: OpenCode, Claude, Codex, Gemini, Copilot, Devin, MCP

> **Prasyarat:** S09 lulus · **Spec:** `00-design.md` §10 · `02-runtime-adapters.md`
> **Estimasi:** 3 jam · **Milestone:** M2

**Goal:** Semua runtime yang diminta tercakup, dengan kejujuran bukti: yang tidak
terpasang tampil `unconfigured`/`offline`, bukan agent palsu.

**Files:**
- Create: `crates/hq-connectors/src/runtime/{opencode,claude,codex,gemini,copilot,devin,mcp}.rs`
- Create: `crates/hq-connectors/tests/fixtures/{opencode.db,claude-session.jsonl,codex-session.jsonl,mcp-config.json,devin-sessions.json}`
- Test: `crates/hq-connectors/tests/{opencode,other_runtimes,mcp_config}.rs`
- Modify: `crates/hq-connectors/src/runtime/mod.rs` (registry)
- Modify: `crates/hq-connectors/src/parity.rs` (subset default semua)

**Interfaces:**
- Consumes: `RuntimeAdapter`, `CollectCtx`, `Probes`, `EventDraft`.
- Produces: adapter OpenCode/Claude/Codex/Gemini/Copilot/Devin/MCP;
  registry runtime lengkap; parity default v2 ⊆ v3.

### Task 1 — OpenCode SQLite (L3)

- [ ] **Step 1: Tulis fixture DB + tes gagal**

Temp DB dengan tabel `session`, `message`, `project` dan 2 sesi (1 parent, 1
subagent), 3 pesan dengan `data` JSON berisi `tokens`, `cost`, `modelID`,
`providerID`, `finish`.

```rust
#[tokio::test]
async fn opencode_session_and_usage() {
    let db = fixture_opencode_db();
    let out = OpenCodeAdapter::new(db.path()).observe(&ctx()).await.unwrap();
    assert!(out.iter().any(|d| d.kind == EventKind::SessionStarted));
    let u = out.iter().find(|d| d.kind == EventKind::UsageRecorded).unwrap();
    assert_eq!(u.payload["input_tokens"], 22183);
    assert_eq!(u.payload["provider"], "opencode");
}

#[tokio::test]
async fn opencode_parent_makes_worker() {
    let out = OpenCodeAdapter::new(fixture_opencode_db().path()).observe(&ctx()).await.unwrap();
    assert!(out.iter().any(|d| d.subject.key().starts_with("agent:opencode/worker/")));
}

#[tokio::test]
async fn opencode_never_stores_message_text() {
    let out = OpenCodeAdapter::new(fixture_opencode_db().path()).observe(&ctx()).await.unwrap();
    let all = serde_json::to_string(&out).unwrap();
    assert!(!all.contains("isi pesan rahasia"));
}
```

- [ ] **Step 2: Jalankan, pastikan gagal.**

- [ ] **Step 3: Implementasi** `opencode.rs`

Baca `~/.local/share/opencode/opencode.db` read-only. Query `session` (id,
parent_id, title, directory, agent, model, cost, tokens_input/output/
reasoning/cache_read/cache_write, time_created/updated) dan `message` (data
JSON: role, agent, cost, tokens, modelID, providerID, time, finish). Session
aktif bila `time_updated` < 5 menit; `finish="stop"` → Santai; `parent_id` →
worker di bawah `agent:opencode/session/<parent>`. Maks 8 sesi + agregat.
Judul sesi boleh menjadi activity; isi pesan tidak pernah dibaca.

- [ ] **Step 4: Jalankan, pastikan lulus.**
